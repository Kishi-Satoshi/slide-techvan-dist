# slide-techvan（配布用）

テクバンのデザイン（紺と白のコーポレートデザイン）で PowerPoint 資料（16:9）を作る Claude のプラグインです。
「〇〇の資料を作って」と頼むと、壁打ちで内容と構成を固めてから、社内テンプレートに沿った .pptx を作ります。

このリポジトリは配布専用です。開発は別の場所で行い、更新のたびにここへ自動で反映されます（直接編集しないでください）。

## 入れ方（Claude デスクトップアプリ）

1. 左下の自分の名前 →「設定」→ 設定の左のメニューの「プラグイン」
2. 右上の「＋ 追加」→「マーケットプレイスを追加」→「リポジトリから追加」
3. URL に `kishi-satoshi/slide-techvan-dist` を入れて「同期」
4. 表示された slide-techvan を「インストール」

画面の画像つきの説明書: https://kishi-satoshi.github.io/slide-techvan-dist/

Microsoft 365 Copilot（Copilot Cowork）で使う場合（試験的）: `cowork/slide-techvan.zip` を Cowork の「カスタマイズ」→「スキル」→「スキルのアップロード」で取り込みます。手順は説明書の「Microsoft 365 Copilot で使う」にあります。

テクバン社内での利用を目的としたものです。
