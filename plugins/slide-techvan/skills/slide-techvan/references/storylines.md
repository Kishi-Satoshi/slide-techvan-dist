# 資料の種類ごとの標準の流れ

構成案を作るときの出発点。枚数や順番は内容に合わせて調整してよい。
（　）内はおすすめのページの型（type）。型の詳細は slide-types.md。

## 提案書（相手に採用・承認してもらう）

1. 表紙（cover）
2. 要約（summary）… 提案の結論と、その理由（2〜4 点。内容に合わせる）。
   相手に判断してほしいこと・期限・規模（費用や期間）を冒頭で示す
3. 背景と課題（bullets / cards）… 相手が困っていること
4. 解決策（cards / process）… 何をするか
5. 案の比較（options）… 他の選択肢と比べて、なぜこの案か
6. 効果（kpi / chart）… 数字で示す
7. スケジュール（schedule）
8. 体制（team）
9. 費用（cost）
10. リスクと対策（risks）
11. 次のステップ（next-actions）… 相手に決めてほしいこと
12. 最終ページ（closing）

## 報告・分析（事実と分析を伝え、提言する）

1. 表紙（cover）
2. サマリー（summary）
3. 調査の概要（bullets / table）… 対象・期間・方法
4. 事実（table / chart / kpi）
5. 分析（cards / tree / matrix）… なぜそうなっているか
6. 提言（cards / next-actions）
7. 注記・出典（notes）
8. 最終ページ（closing）

章が分かれる長い資料では、章の頭に章扉（section）を入れる。

## 社内報告（状況を共有し、判断や協力をもらう）

1. 表紙（cover）
2. 結論（summary / bullets）… 一番伝えたいこと
3. 進捗・数字（kpi / status / chart）
4. 課題と対策（risks / cards）
5. 次のアクション（next-actions）… 誰が・いつまでに・何を
6. 最終ページ（closing）※省略可

## 営業資料（興味を持ってもらい、次の商談につなげる）

1. 表紙（cover）
2. 課題提起（bullets / quote）… 相手の「あるある」
3. 解決策（cards）
4. 特長（cards）… 2〜4 個に絞る（数は内容に合わせ、3 にこだわらない）
5. 事例（compare / kpi）… 導入前と後
6. 導入の流れ（process）
7. 費用（cost）
8. よくある質問（faq）
9. お問い合わせ（closing）

## 画像の入れ方

文字と表だけのページが続くと、読み手が疲れて要点が残りにくい。構成案の時点で、画像を置くページを決める。

- **目安**: 本文のページの 4〜5 枚に 1 枚は、画像（画面の写し・写真・図・挿絵）か、アイコンを大きく置いたページにする。
  ただし、内容に合わない絵は置かない（飾りのためだけの画像は入れない）。
- **置きやすい場所**
  - 特長・解決策・理由（cards）: 各項目に `icon` を付け、`"icon_size": "large"` で大きく置く（4 個まで）。
  - 手順・対策（bullets）: 同じく `icon` と `"icon_size": "large"`。
  - 画面・帳票・製品・現場の様子（figure）: 利用者から受け取った画像を置く。無ければ、同梱の挿絵で代わりになるものがあるときだけ使う。
  - 章扉（section）: `illustration` で挿絵を 1 枚。1 つの資料で 1〜2 枚まで。
- **素材の優先順**: ① 利用者から受け取った画像（画面の写し・写真・ロゴ・図）→ ② 同梱のデジタル庁のアイコン・挿絵 → ③ 公的機関の素材（下）。
  ネットの画像を勝手に探して入れない。
- **公的機関の素材**（使うときは利用者に確かめ、出典を caption か note に書く）
  - 地図: 国土地理院の地理院地図。画面の写しを利用者に用意してもらい figure に置く。出典の例「出典：国土地理院 地理院地図」。
    社外に配る資料に使うときは、申請が要るかを国土地理院の「地図の利用手続ナビ」で確かめてもらう。
  - 統計・白書の数字: 画像を貼らず、数字を chart・kpi・table の型で作り直す。note に「出典：総務省『令和○年版 情報通信白書』」のように書く。
    数値や簡単な表・グラフは自由に使える（公共データ利用規約 第1.0版）。
  - 府省の図や写真をそのまま使うときは、公共データ利用規約 第1.0版に従い出典を書く。加工したときは、加工したことも書く。
    権利表記がある写真（第三者の著作物）は使わない。

## 迷ったときの型の選び方

| 伝えたいこと | 型 |
|---|---|
| 結論と根拠をまとめて | summary / bullets |
| 数字のインパクト | kpi |
| 並列の理由・特長（2〜6個） | cards |
| 一覧・比較の詳細 | table |
| 推移・構成比 | chart |
| 前後・現状とあるべき姿 | compare |
| 複数案の評価 | options |
| 手順・段階 | process |
| 原因の分解 | tree |
| 優先順位づけ | matrix |
| 画面・帳票・現場の様子 | figure |
| 日程 | schedule |
| 誰が何をするか | team / next-actions |
| 未解決の問題と状況 | status / risks |
